# Plans

Status: ACTIVE
Owner: repository
Last verified: 2026-08-08

Small changes may use an ephemeral local plan. Complex, multi-step, architectural, safety-critical, or long-running work requires a checked-in execution plan under `docs/exec-plans/active/`.

Every execution plan contains: goal, non-goals, baseline, acceptance criteria, progress log, decision log, verification evidence, risks, and single next action.

Move a plan to `completed/` only when its acceptance criteria have objective evidence. Rejected work and technical debt remain discoverable; do not erase failed hypotheses or unresolved gaps.
