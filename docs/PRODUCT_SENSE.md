# Product Sense

Status: ACTIVE
Owner: repository
Last verified: 2026-08-08

The product is not "an autonomous trader." It is a governed research and decision system whose outputs are only as valuable as their evidence, reproducibility, and failure containment.

Optimize for:
1. verified correct outcomes;
2. capital preservation;
3. point-in-time integrity;
4. traceability and replay;
5. economically efficient use of models and human attention;
6. incremental autonomy only after controls are encoded and verified.

Do not optimize for raw agent count, token volume, code volume, PR volume, win rate, or headline P&L in isolation.
